Use Case & Architectural SpecificationStory Key & Title: SCRUM-38 (SKN-12 — Angular shell, routing, AR/EN + RTL)   Requirements Covered: NFR-05 (Bilingual EN/AR localization), NFR-07 (RTL layout & logical CSS)   Actors: Anonymous Visitor, Authenticated User (BUYER_TENANT, OWNER, AGENT, ADMIN)   Preconditions:The Angular SPA bundle is loaded in a modern browser.Translation dictionaries (assets/i18n/en.json and assets/i18n/ar.json) are accessible via static assets.   Postconditions:The application shell (NavbarComponent + <router-outlet>) renders with strictly logical Tailwind CSS classes (ms-*, me-*, ps-*, pe-*, text-start, text-end, border-s, border-e).   The root <html> element maintains synchronized lang ("en" or "ar") and dir ("ltr" or "rtl") attributes matching the active language.   Lazy-loaded feature bundles (auth, admin, listings, viewings) are fetched on demand.   Outgoing HTTP requests carry Authorization: Bearer <token> when a valid JWT exists in TokenStorageService.   Main Flow of Events (Shell Initialization, Lazy Routing, RTL Switching, & Auth Interception)Bootstrap & Language Initialization:On application startup (AppComponent initialization), LanguageService checks localStorage for a saved language preference (sakan_lang), defaulting to 'en' if none is stored.LanguageService calls TranslocoService.setActiveLang(lang) and updates document.documentElement.lang ("en" or "ar") and document.documentElement.dir ("ltr" or "rtl").   Shell Rendering & Role-Aware Navigation:AppComponent renders NavbarComponent and <router-outlet>.NavbarComponent reads the current user's authentication and role state from TokenStorageService signals and renders navigation links (listings, viewings, admin if ADMIN, or auth login/register if unauthenticated) alongside the EN / AR language toggle.   Bilingual & RTL Switching Flow:The user clicks the language toggle button in NavbarComponent.   LanguageService.toggleLanguage() switches the active language between 'en' and 'ar', persists the choice in localStorage, updates TranslocoService, and mutates <html dir="rtl" lang="ar"> (or <html dir="ltr" lang="en">).   Because all shared UI and layout templates exclusively use Tailwind logical properties (ms-*, me-*, ps-*, pe-*, text-start, border-s), the entire layout mirrors immediately without component reload or physical directional overrides.   Lazy Feature Navigation Flow:The user clicks a navigation link (e.g., /viewings or /listings).   Angular Router matches the path in app.routes.ts and dynamically imports the corresponding feature route configuration (viewings.routes.ts, listings.routes.ts, auth.routes.ts, or admin.routes.ts).   Protected routes invoke authGuard to verify TokenStorageService.isAuthenticated() before activating the route.Stateless JWT Auth Interception Flow:When any feature service issues an HttpClient request to /api/..., authInterceptor intercepts the outgoing request.   authInterceptor queries TokenStorageService.getToken(). If a JWT is present, it clones the request and attaches the Authorization: Bearer <token> header.   Alternate & Exception Flows4a. Unauthenticated Access to Protected Route:If an anonymous user navigates to a protected route guarded by authGuard, the guard blocks activation and redirects the user to /auth.   5a. Missing JWT on Outgoing Request:If TokenStorageService.getToken() returns null (e.g., public property browsing or login request), authInterceptor forwards the original request unmodified without an Authorization header.   5b. Expired or Invalid JWT (401 Unauthorized Response):If the backend returns 401 Unauthorized (ProblemDetail), authInterceptor catches the error via catchError, invokes TokenStorageService.clear() to purge the stale token, redirects the user to /auth, and rethrows the error to the subscriber.
